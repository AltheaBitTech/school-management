# Implement Feature

Use this workflow whenever implementing a meaningful feature.

## Steps

1. Read `docs/00-IMPLEMENTATION-BLUEPRINT.md`.
2. Read the most relevant domain/workflow documentation.
3. Inspect the existing module(s) and similar features.
4. Define the acceptance criteria.
5. Identify database changes.
6. Identify API changes.
7. Identify permissions and tenant checks.
8. Implement backend.
9. Implement frontend.
10. Add audit/notification behavior where required.
11. Add/update tests.
12. Run validation.
13. Review the diff for unnecessary changes.
14. Update documentation when the architecture or contract changed.

## Final response

Summarize:
- What changed
- Files changed
- Tests run
- Any assumptions
- Any remaining follow-up
