# Review Code

Review the selected change as a production engineer.

Check:

- Architecture/module ownership
- Tenant isolation
- RBAC/permissions
- BOLA/IDOR
- Validation
- Transactions/concurrency
- Error handling
- API contract
- Frontend loading/error/empty states
- Accessibility/UX consistency
- Performance/query patterns
- Test coverage
- Logging/secrets
- Unnecessary complexity

Report findings by severity:

1. Critical
2. High
3. Medium
4. Low

Do not invent issues without evidence from the code.
